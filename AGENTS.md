# Agent instructions

Guidance for AI coding agents working in this repository.

## Pull requests

- When creating and/or updating a PR, make sure that the description exactly
  reflects the code changes — break it down for the reviewer. Every claim in the
  description must map to something in the diff, and every non-trivial change in
  the diff should be described. Do not reference files, flags, or behaviour that
  are not in the branch; when the code changes, update the description to match.
